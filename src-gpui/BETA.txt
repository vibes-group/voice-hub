Voice Hub - GPUI Beta (Windows x86_64)

Extract the entire ZIP, including native/ and licenses/, and run
voice-hub-gpui-beta.exe. Enter your HTTPS server, name and password.
Chat is available before joining voice. Closing the window keeps the
application in the tray; use Exit in the tray menu to quit.

Voice: selectable devices, mute/deafen, echo cancellation, automatic gain,
RNNoise, FastEnhancer Tiny/Base, WebRTC noise suppression and TURN relay.
Screen sharing: screens/windows, system audio, AV1/VP9, quality settings,
multiple viewers, focused view and reconnect/resume.
Chat: persistent history, attachments, images, video playback, downloads,
retry/cancel, local file deletion and message deletion.
Desktop: participant preferences, pings, administration, global keyboard
and mouse bindings, autostart, tray and signed automatic updates.

Settings and history use a separate GPUI profile. Session credentials are
stored in Windows Credential Manager; connection passwords are never saved.
Updates come from your own server at /desktop/gpui-latest.json.

The native/ archive contains the pinned LGPL FFmpeg fallback decoder and
its license notices. It is verified before extraction or execution. The
server mirror also provides this archive for standalone EXE installations.

This is a beta. Audio hardware, capture permissions, graphics drivers and
real calls still require testing on the target Windows machines. A performance
improvement over the stable client has not been established by measurement.
